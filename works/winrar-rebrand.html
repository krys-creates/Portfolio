# other collaborators:

< PHASE 01: DESIGN RESEARCH >

The Heritage Challenge: The original ‘three books and a belt’ logo carries immense global recognition, but its 2000s-era Windows aesthetic feels visually outdated

Outgrown Metaphors: The belt element explicitly communicates physical ‘zipping’, which fails to represent WinRAR’s full suite of modern, multi-functional capabilities

Industry Landscape: modern tech branding favors minimal, geometric, and highly scalable forms that translate effortlessly across modern UI platforms

// old design

STRATEGIC DIRECTION

Retain the iconic three-book motif for instant recognition, but execute it through thoughtful, minimal simplification.

< PHASE 02: RE-BRAND >

The illustrative books are transformed into three minimal, stacked rectangles. This layout visually conveys compressed data blocks, modularity, and structured security without relying on an outdated metaphor

Eliminating the belt opens up the visual narrative, signaling that WinRAR is a comprehensive data management tool, not just a compression utility
